# Règles du projet UI-OriginRP

## Création d'items GTA RP

Pour toute demande de création d'item (arme, vêtement, accessoire, objet, etc.), TOUJOURS livrer :

1. **Script Lua** (`.lua` complet et fonctionnel) :
   - Configuration de l'item (id, nom, propriétés)
   - Mécaniques spéciales (utilisation, animation, effet)
   - Intégration serveur (jobs, permissions, drop, etc.)

2. **Aperçu interactif HTML** (un seul fichier, prêt à ouvrir dans le navigateur) :
   - Rendu 3D stylisé de l'item (SVG ou Canvas)
   - Animations de l'item en action
   - Dashboard de stats/propriétés
   - Boutons interactifs (Utiliser, Inspecter, etc.)
   - Effets visuels (glow, rotation, impacts)
   - Design cyberpunk/GTA sombre cohérent, animations fluides, UI moderne
