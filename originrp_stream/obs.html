Liens OBS Origin Roleplay

Les bannières et écrans animés du kit stream, prêts à mettre dans OBS.

Dans OBS
  1. Sources › + › Navigateur, puis nommer la source.
  2. Décocher Fichier local et coller l'adresse copiée ci-dessous dans URL.
  3. Régler Largeur et Hauteur sur la taille indiquée sous le visuel.
  4. Cocher Actualiser le navigateur quand la scène devient active pour rejouer l'animation d'entrée.

Ajouter &intro=0 à une adresse pour afficher le visuel sans l'animation d'entrée. Pour un autre streamer : tiktok/banniere-haut.html?nom=Pseudo&role=Streamer officiel&perso=fichier.png (image détourée dans commun/persos/).
